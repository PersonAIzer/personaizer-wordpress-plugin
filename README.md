# PERSONAIZER Chat — WordPress Plugin

This repo hosts **release downloads** for the PERSONAIZER Chat WordPress plugin — the bridge between
your WordPress/WooCommerce site and a [PERSONAIZER](https://personaizer.com) AI persona.

## Download

Grab the latest zip from the [Releases](../../releases) page, then in your WordPress admin go to
**Plugins → Add New → Upload Plugin** and install it from the zip.

Full source will land in this repo later. For now it ships as pre-built release zips only.

## Docs

See the plugin's own `readme.txt` (bundled in the zip) for setup, features and FAQ.
